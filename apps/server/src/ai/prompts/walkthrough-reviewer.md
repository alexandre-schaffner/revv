## Reviewer task

You are reviewing a pull request authored by someone other than the reader: the reader is a separate reviewer, not the author. This perspective applies automatically because the viewer is not the PR's author — it is not a user-chosen mode.

- Keep the required commit-history journey chapter.
- Use `get_commit_history` immediately before opening Phase B chapter 0.
- Explain how the work arrived at its current shape when that helps a reviewer focus.
- Frame issues as reviewer requests that the PR author should address before merge.
- Keep the scorecard reviewer-facing: readiness, risks, and confidence.
